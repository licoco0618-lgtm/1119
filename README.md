# 數位科技概論（上）線上練習與模擬測驗平台

本練習網站專為技術型高中／高中課程《數位科技概論（上）》打造，完整收錄資料夾中第 3 章至第 6 章之**隨堂測驗卷**與**習作本**題目，共計 **103 題完整題庫**，並附帶所有標準答案與詳細精解說明。

---

## 🚀 如何開啟網站？

本平台為**純前端單頁式應用（SPA）**，不需要安裝 Node.js、資料庫或後端環境：
1. 直接在檔案總管中雙擊 [`index.html`](file:///c:/Users/User/Desktop/Final/index.html) 即可使用 Chrome、Edge 或任何瀏覽器開啟。
2. 或在終端機啟動任何本地伺服器（例如 `python -m http.server 8000` 或 VS Code Live Server）。

## 🌟 核心特色功能

### 1. 🎯 刷題練習模式 (Practice Mode)
- **章節篩選**：可選擇「全範圍 (103題)」、「第 3 章 硬體 (35題)」、「第 4 章 軟體與網路 (35題)」、「第 5 章 運作與發展 (23題)」、「第 6 章 辦公室與影音 (10題)」。
- **即選即答反饋**：點擊選項後立刻顯示是否正確，並附上「💡 精解說明」。
- **題目導航板 (Palette)**：點開導航板可一覽所有題目的答題狀態（🟩 正確、🟥 錯誤、⬜ 未答），點擊即可秒跳題。
- **重練此題**：做完可隨時一鍵清空當前題重答。

### 2. ⏱️ 模擬全真測驗模式 (Exam Mode)
- **自訂測驗**：可自選章節範圍與測驗題數（20 題、30 題、50 題或全題目）。
- **倒數計時器**：仿造升學與學測倒數時間，提高臨場應試感。
- **考卷結算**：提交後立刻結算百分制成績、答對題數、答錯題數，並提供整份考卷的詳細題目與精解回顧。
- **錯題自動匯入**：測驗中答錯的題目會自動同步加入「錯題本」。

### 3. ❌ 專項錯題本 (Mistakes Mode)
- 自動記錄平時刷題與模擬測驗寫錯的題目。
- 支援「我已經學會了」一鍵移出，也可答對後自動清除，幫助考試前快速掃描弱點。

### 4. 📖 考點速記表 (Flashcards Mode)
- 整理教材最常考的重點表格：
  - 電腦五大單元與功能
  - CPU 機器週期四步驟（擷取、解碼、執行、儲存）
  - DRAM vs SRAM 深度對比表
  - 儲存設備存取速度排行榜
  - 雲端運算架構三層次（IaaS、PaaS、SaaS）
  - 作業系統行程五大狀態與排程演算法
  - 主流辦公室軟體與多媒體工具對照表

### 5. 🔍 題庫搜尋引擎 (Browse Mode)
- 支援全題庫即時關鍵字模糊搜尋（如搜尋「SRAM」、「Linux」、「ppm」、「工作管理員」等）。

### 6. 輔助功能
- 🌙 **深色模式 / 淺色模式切換**：保護眼睛，深夜刷題更舒適。
- 💾 **進度本地記憶 (LocalStorage)**：答題進度、錯題記錄、收藏星號自動保存在瀏覽器，關閉網頁下次打開進度依然在。
- ⌨️ **鍵盤快捷鍵**：
  - `A` / `B` / `C` / `D` 或數字 `1` / `2` / `3` / `4`：快速選答案
  - `←` / `→` 方向鍵：快速上一題 / 下一題
